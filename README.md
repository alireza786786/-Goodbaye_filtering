* 🔄 **به‌روزرسانی خودکار:** اجرای اتوماتیک هر ۴ ساعت یک‌بار توسط GitHub Actions.
* 🧪 **تست پینگ واقعی:** بررسی اتصال تمام پروکسی‌های تلگرام و مرتب‌سازی بر اساس کمترین پینگ.
